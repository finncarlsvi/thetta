# Thetta

Thetta is a Rust application for 2D irregular polygon nesting and CAM from
STEP-derived profiles, with desktop and browser interfaces.

## Documentation

- [Architecture](docs/ARCHITECTURE.md)
- [Automatic CAM and cutting database](docs/AUTOMATIC_CAM.md)
- [Sprint Docs](docs/sprints/)

## Run

```bash
cargo run -p thetta-app
```

## Test

```bash
cargo test --workspace
```

## Website

A browser version with STEP upload, nesting, and CAM exports is available.
See [web usage and deployment](docs/WEB.md).
