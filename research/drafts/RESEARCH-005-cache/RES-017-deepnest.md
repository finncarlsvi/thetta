# RES-017: Deepnest — Open Source Nesting
**URL**: https://github.com/Jack000/Deepnest
**Type**: Code
**Status**: CACHED

## Content
- Open source nesting application for laser/plasma cutters and CNC machines
- Packs parts into compact area to save material and time
- **Key feature**: automatically merges common lines so laser doesn't cut same path twice
- Reduces heat warping from multiple laser passes
- Supports SVG, DXF
- Path approximation for complex parts
- Built on SVGNest, with C-based nesting engine for performance
- Architecture: JS (78.5%), HTML/CSS, C++ (1.5%)
- No explicit tab/bridge placement feature documented
- Relevance: common-line merging is related to shared-tab problem
