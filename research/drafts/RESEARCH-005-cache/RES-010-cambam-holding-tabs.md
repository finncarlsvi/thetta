## From Search Results
- **Automatic tab count formula**: Number of tabs = perimeter ÷ Tab Distance, rounded to nearest whole number
  - Example: 160mm perimeter with 30mm tab distance = 160/30 ≈ 5 tabs
- Clamped between Minimum Tabs and Maximum Tabs properties
- **Size Threshold**: if shape's perimeter < threshold, no tabs inserted
- Tab Style options available
- Tab Width and Tab Depth configurable
- This is one of the most explicit algorithmic descriptions of automatic tab placement found
