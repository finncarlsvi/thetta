# RES-013: bCNC — GRBL CNC Sender with Cutout Tabs
**URL**: https://github.com/vlachoudis/bCNC
**Type**: Code
**Status**: PARTIAL

## Content
- GrblHAL CNC command sender, autoleveler, G-code editor, digitizer, and CAM tool
- Cross-platform, written in Python
- CAM features: profiling, pocketing, drilling, flat/helical/ramp cutting, thread milling, cutout tabs, drag knife
- Tab functionality integrated into the "cut" tool
- Important: default settings have "only leave selected islands uncut" checked — must uncheck for tabs to work
