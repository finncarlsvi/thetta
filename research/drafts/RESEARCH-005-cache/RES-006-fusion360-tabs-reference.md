# RES-006: Fusion 360 Tabs Reference (Autodesk)
**URL**: https://help.autodesk.com/view/fusion360/ENU/?guid=MFG-REF-2D-CONTOUR-TABS
**Type**: Commercial
**Status**: PARTIAL (JS bootloader only)

## From Search Results
- Tab holds the part to the stock — short thin piece of material so part doesn't move
- Tab Shapes: Rectangular or Triangular
- Tab Positioning: "By distance" (Fusion places tabs at intervals) or "At points" (manual)
- Tab Distance parameter only available in "By distance" mode
- Recommended Tab Height for through cuts: 0.1125"
- For through cuts, set bottom of cut to -0.05" below stock bottom, make tabs higher to compensate
- Visual inspection recommended after automatic placement
- Known issue: tabs with Control Compensation — set to "Computer" for correct toolpaths
