# RES-027: Creating and Using Tabs in Mastercam
**URL**: https://blog.caminstructor.com/creating-and-using-tabs-in-mastercam
**Type**: Community
**Status**: CACHED

## Content
- Integrated into 2D Contour toolpath
- Edit via right-click on chain → "Edit Tabs"

### Placement Methods
- **Automatic**: specify number of tabs OR maximum distance between tabs
- **Manual**: create square points along contour using Point Position

### Configuration
- Tab thickness and width fully customizable
- Side profile: vertical or any desired angle
- Also works in Window Machining and 5-axis parting

### Key Feature
- Balance between simplicity (automatic) and precision (manual)
