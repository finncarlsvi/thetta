# RES-014: bCNC Tabs Tool Tutorial
**URL**: https://github.com/vlachoudis/bCNC/wiki/Tutorials:-Tabs-tool
**Type**: Community
**Status**: PARTIAL

## Content
- Tabs prevent pieces from moving during cutting
- Select the last pass block to add tabs
- Click "Execute" to add tabs (default: 3 tabs on last pass)
- Links to external PDF guide for detailed configuration
- Critical warning: must uncheck "only leave selected islands uncut" in cut tool settings
