# RES-011: FreeCAD CAM DressupTag (Holding Tags)
**URL**: https://wiki.freecad.org/Path_DressupTag/en
**Type**: Code
**Status**: CACHED

## Content
- Dresses up existing path (usually 2D contour) to leave tags holding part in place
- Tags intended to be broken off by hand or chisel, then filed flat
- **Parameters**: Angle (plunge/ascent), Height (from bottom of profile cut), Radius (fillet), Segmentation Factor, Width
- **Automatic placement**: Tags generated evenly spaced along contour, beginning with largest edge
- Users can adjust by deleting or repositioning tags
- Tags want to be on convex sections (easier to file down)
