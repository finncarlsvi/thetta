# RES-008: How to position tabs for cutting out adjacent pieces (Autodesk Forum)
**URL**: https://forums.autodesk.com/t5/fusion-manufacture-forum/how-to-position-tabs-for-cutting-out-adjacent-pieces/td-p/12566903
**Type**: Community
**Status**: FETCH_FAILED (403)

## From Search Results
- Key problem: tabs placed on one part can be destroyed when adjacent part is cut
- If duplicate tabs aren't placed on adjacent parts lining up in same location, other parts' tabs are cut away
- Solutions: draw tabs by hand, or space parts farther apart so CAM software places them without interference
- Manual edge selection workaround: select each edge for bit to follow, able to move pieces back to 1/4" gap and have it follow tabs
